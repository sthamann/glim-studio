# Format presets

Verified 21 September 2026 where official guidance is available. These presets set the composition ratio and final PNG dimensions. The generation grid is rounded to multiples of 32; output is centered, cropped slightly as needed and resized to the target. This is resampling, not AI upscaling. Draft may be smaller than the output; 2K generates more detail. Edits with references follow the first reference and do not apply these presets.

| Preset | Saved PNG | Basis |
|---|---:|---|
| X profile header | 1500 × 500 | X recommendation |
| X profile picture | 400 × 400 | X recommendation |
| X article cover | 2500 × 1000 | Suggested 5:2 composition; X does not specify dimensions in the linked Articles guide. Verify in its editor. |
| LinkedIn profile banner | 1584 × 396 | LinkedIn recommendation |
| LinkedIn profile picture | 400 × 400 | Square profile composition |
| LinkedIn article / newsletter | 1920 × 1080 | LinkedIn recommendation |
| LinkedIn company cover | 1512 × 256 | Current LinkedIn Page recommendation |
| LinkedIn link post | 1200 × 627 | LinkedIn recommendation |
| Social square | 1080 × 1080 | General-purpose layout |
| Social portrait | 1080 × 1350 | General-purpose 4:5 layout |
| Social story / reel cover | 1080 × 1920 | General-purpose 9:16 layout |
| Presentation | 1920 × 1080 | General-purpose 16:9 slide |
| Website hero | 1920 × 640 | Suggested wide layout; adapt to the site's design |
| Product image | 2048 × 2048 | General-purpose square product layout |
| A4 document cover | 1240 × 1754 | A4 proportions at approximately 150 pixels per inch |

Keep key subjects centered. Social networks may crop images differently on mobile or cover portions with profile photos. Pixel dimensions do not guarantee a platform's file-size limit; Glim currently exports PNG without a platform-specific compression budget.

Sources: [X profile guidelines](https://help.x.com/articles/166743), [X Articles](https://help.x.com/en/using-x/articles), [LinkedIn profile cover](https://www.linkedin.com/help/recruiter/answer/a568217), [LinkedIn Pages and link posts](https://www.linkedin.com/help/linkedin/answer/a563309/image-specifications-for-your-linkedin-pages-and-career-pages?lang=en), [LinkedIn article covers](https://www.linkedin.com/help/linkedin/answer/a517899/).
